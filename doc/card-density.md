# 标准与紧凑卡片浏览

核对日期：2026-10-19。基线 `d109ca0`；承接 Issue #2 和 507 确认的最终预览：标准保留 3∶4，紧凑随内容收缩，底部信息紧跟内容。本轮范围为独立版源码，插件适配版尚未迁入，不代表共同版本已交付。

## 实现接缝

- `web/app/atlas.tsx` 在卡片浏览标题区域提供标准／紧凑按钮，使用原生按钮及选中语义。密度与画布临时聚合状态分离，仅在同页保留，重新加载页面恢复标准。
- `web/app/card-browser.tsx` 在改变密度前捕获首张可见卡片的标识与相对顶部偏移，布局完成后恢复。顶部已滚出的长卡片收缩时保留一段可见内容；底部按实际滚动边界处理。密度不进入范围键，不清空展示批次；无限滚动仍每次追加 50 条，并在密度改变时重新观察末尾。
- `web/app/globals.css` 的紧凑规则限定在卡片浏览的密度属性下，复用 `InspirationCard` 的原内容、封面顺序、摘要回退、标签、计数与可访问名称。紧凑卡片不设固定高度，内边距 12px，标题与摘要各最多两行，封面 64px，底部间距 6px；画布预览不进入该作用域。
- 服务端、数据库、MCP、CLI、附件、关系与画布布局规则没有修改，没有增加依赖。密度不跨刷新存储，不引入瀑布流、额外摘要字段或第二份资料。

## 工程与网页验证

Node.js 22.22.3，`npm run check` 的类型检查、生产构建与 60/60 自动测试通过，`git diff --check` 通过。现有排序与筛选测试继续有效；本轮新增的布局、锚点与观察行为通过实际生产网页验证，不以现有单元测试替代。

使用 Ego Browser 与独立临时 SQLite／附件目录，180 条自编记录中有 168 条活跃、12 条归档，包含长短标题与正文、有图／无图、多标签／无标签和一条已说明关联。未读取或写入私人资料库。桌面检查包含真实窗口及 1280×760 模拟，窄屏采用 390×735 CSS 像素模拟，尺寸从页面读回。

| 动作 | 结果与证据范围 |
| --- | --- |
| 桌面标准与紧凑呈现 | 标准卡片保持 3∶4；紧凑样例随内容约 118–170px，日期和附件数量紧跟主体，长标题、摘要及标签保持可读 |
| 窄屏密度与键盘切换 | 390×735 下标准约 358×477px；紧凑约 119–171px，无横向溢出或标签／底部信息覆盖；Enter 与空格可切换 |
| 实际滚轮后标准→紧凑→标准 | 同一阅读卡片保持；普通锚点偏移误差小于 1px，已展示的 50 条没有重置；长卡片部分滚出后收缩保留约 24px 可见内容 |
| 画布与卡片往返 | 卡片滚动与批次保持，密度保持，原画布变换保持 |
| 连续滚轮追加 | 观察到 50→100→150→168，末尾数量正确，无重复记录；原实现的 50 条批次规则保持 |
| 隐藏卡片后扩大视口 | 隐藏时仍为 50 条；重新显示后自动补到 168 条，顶部保持。大视口只用于验证补足条件，不代表真实大屏性能 |
| 搜索、标签组合与归档 | 空结果回到顶部；搜索和标签组合 14 条，两种密度的 ID 序列一致；归档 12 条且状态可辨，清除范围后从首批 50 条开始 |
| 详情、关系说明与显式定位 | Enter／空格打开共用详情，关闭后回原卡片；关系说明在卡片模式打开并回到发起卡片；定位操作显式返回画布；画布预览仍为 300×400px |
| 直接关联范围 | 同一组 2 条记录在两种密度一致，返回全部后从首批开始 |
| 冷加载及刷新失败 | 浏览器侧仅延迟或拒绝 `/api/atlas` 读取以注入故障：紧凑加载占位 3 个、高 148px；加载完成后 50 条。已有资料刷新失败保留卡片，重试后密度仍为紧凑；不将故障注入称为真实服务器故障 |
| 浏览与数据保护 | 在显式定位和实际拖动之前，完整 `/api/atlas` 与起始快照逐项相同，浏览写入为 0，覆盖记录、附件元数据、关系、坐标和持久视野 |
| 实际画布拖动 | 用原指针路径移动节点，持久坐标实际变化、关联保持；筛选中实际拖动只改变临时位置，切密度并往返后临时位置保持，完整 Atlas 不变。单独于零写入浏览检查记录，不把主动拖动算作密度引入的写入 |

滚动首次脚本在滚轮尚未结束时取样导致偏移断言失败，后续等待滚动稳定并核相同动作；早期 End 键未产生预期滚动，改用实际滚轮，并记录全部批次转换。窄屏指针模拟的坐标未可靠命中时，使用真实焦点与键盘动作验证，不声称完成真机触摸。关系说明关闭后的焦点等待返回帧再判断，不以关闭瞬间代替最终焦点。

隔离夹具、HTTP 前后快照、浏览回执、截图和工程日志存于源码树外。公共文档不包含个人环境、实例身份、私人内容或完整备份。复验时用新临时资料库，从网页入口重复本表并比对完整 Atlas；受控失败只针对临时页面读取，不操作真实资料库。
