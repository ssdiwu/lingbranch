# 两种运行方式的边界

LingBranch 独立版是共同产品要求的维护主线，插件适配版在既有站点运行。共同交付规则由 [AGENTS](../AGENTS.md#共同功能同版交付)唯一维护；这里说明已核实的运行差异和维护接缝，不保存另一项目的私人部署标识或动态进度。

## 共同要求与适配

灵感、正文图片、文件原件、标签、连线、画布与临时视图的共同词义沿 [GLOSSARY](../GLOSSARY.md)维护；关系优先画布、标准／紧凑卡片密度、图文交错与反馈沿 [DESIGN](../DESIGN.md)维护。现行行为与验收以 [spec](../spec/local-first-library.md)为主；适配版回链共同部分，并说明身份、存储、入口及兼容合同。两版各自的资料库继续独立，不由功能同步复制个人资料。

| 维度 | 独立版 | 插件适配版 |
| --- | --- | --- |
| 持久化 | SQLite 与附件目录；库内统一操作负责持久事实 | D1 记录与 R2 原件；按平台已认证身份限定记录范围 |
| 访问保护 | 本机信任边界；服务器模式使用部署者配置的保护 | 沿用 Sites 身份、原插件与现行访问范围 |
| 内容浏览 | 默认关系画布，可切到无限滚动卡片，共用筛选与详情，各自保留同页位置 | 同一共同规则，保留平台登录及会话边界；两侧资料库继续独立 |
| 卡片密度 | 标准 3∶4 与按内容收缩的紧凑预览，验证与交付边界见 [密度记录](card-density.md) | 已适配标准／紧凑密度并部署原站第25版，工程、路径、审查及真实读回见 [密度记录](card-density.md) |
| 多人访问 | 同一个实例是一份库，访问令牌不建立多用户隔离；各人可自行部署 | 可准备公开介绍与登录入口，按平台认证账号隔离资料；实际开放须另经授权与双真实账号验收 |
| AI 入口 | 本地 stdio MCP、CLI；受保护 HTTP 资料操作接口 | 平台管理的 HTTPS MCP；已登录网页同源工具入口 |
| AI 任务辅助 | 当前 AI 按技能定向检索、读原文推荐，授权保存时补标签；安装及加载单独验证 | 沿共同要求，保留平台身份、搜索前六词／最多二十条、旧标签别名；本地技能加载与平台工具说明发布分别验证 |
| 工具边界 | 0.0.4实现提供15个工具，包含分段读取附件、整批位置和关系说明更新 | 0.0.4实现提供16个工具，包含图片查看、分块原件导入、整批位置和关系说明更新；工具数量不作为一致性判据 |
| 原件上限 | 20 MiB | 沿用原接口的 20 MB |
| MP4 视频 | 已通过隔离网页上传、播放定位、原件下载与备份恢复验收 | 原站第23版已交付；第24版真实登录同源工具目录仍包含 `video/mp4`，当前会话预加载的旧工具定义缓存另行核对，未向真实资料库上传验收文件 |
| 索引能力 | UTF-8 文本和手填关键文字；不提供图片 OCR／PDF 全文识别 | 网页保留 PDF 文字层提取和按需 OCR；聊天导入只保存原件及支持的静态索引 |
| 导出／恢复 | 格式3 JSON gzip资料包，可隔离恢复，兼容v1/v2 | 格式3 tar.gz清单与原件；不将其描述为可直接导入独立版 |

以上差异保留各自现行合同。能力、上限或格式的后续改变须回到对应规格和验证；不通过复制部署配置、放宽校验或统一数字使两版看似相同。

托管版的账号隔离是用户之间的访问隔离，数据库与原件仍由站点维护者管理；需要自行掌握存储的人使用独立部署版。公开介绍、平台登录、用户资料权限及AI工具接入分别核验，不把站点可访问描述为私人资料可公开读取。本轮认可该方向并先做本地准备，不能据此推断某个现有私人实例已开放。

## 维护接缝

共同 Markdown 语义、编辑器体验与保存规则当前存在于各自源码中；平台层分别提供持久化、原件传输及身份校验。同步时先核对共同要求和两侧基线，再逐项认领必要差异；当前不存在自动同步工具或跨项目检查器。

每侧的交付维护者更新自己的 PROGRESS，完成结果归入自己的 doc。共同版本的验收应逐项覆盖本次变化相关的网页与 AI 路径、失败／重试、冲突、原件完整性、持久化和访问保护，按支持环境裁剪并保留未覆盖项。发布结果分别读回，所需外部授权由对应项目规则控制。

共享代码的具体组织与自动门禁建设属于后续工程设计，不能由本说明推断为已经实现。独立版当前证据见 [验证记录](verification.md)及 [版本交付](release-0.0.2.md)；当下未完成事项见 [PROGRESS](../PROGRESS.md)。
