# 关系画布实现与验证

核对日期：2026-10-08。本记录针对 0.0.2 之后的实现与渠道交付；源码产品版本、公共发行和插件部署分别记录。要求沿 [现行规格](../spec/local-first-library.md#画布连线与归档)，视觉层级沿 [DESIGN](../DESIGN.md)，当前交付依赖见 [PROGRESS](../PROGRESS.md)。

## 工程接缝

- [Atlas](../web/app/atlas.tsx)保留原有图文编辑、详情、原件、全量列表与归档，主画布改为节点和标题；[预览组件](../web/app/relationship-preview.tsx)只呈现 3∶4 卡片，不持有另一份正文或位置。
- [共用几何与排列](../shared/relationship-layout.mjs)提供节点 200×88、预览 300×400、直接邻居及确定性的关联分组；新建位置使用相同节点边界。已有坐标继续读回，主动整理才保存新位置。
- [位置参数](../shared/layout-request.mjs)限定有效 ID、坐标、版本、稳定请求键及 1000 条上限。[Library](../server/library.mjs)先检查全部版本，再在一个事务中修改位置和保存原坐标回执；[工具分发](../server/tools.mjs)供网页、CLI 与 stdio MCP 使用。
- 恢复回执的操作与限度见 [接口合同](interfaces.md#整批位置与恢复)。回执仅备份坐标与版本；完整资料继续沿原资料包导出／隔离恢复。
- 拖动和键盘位置写入在整批操作前完成，迟到回执保留较新版本；整批结果还需回读当前资料。图文编辑的草稿、原件和保存流程保持原职责。
