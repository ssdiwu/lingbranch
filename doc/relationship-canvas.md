# 关系画布实现与验证

核对日期：2026-10-07。本记录针对 0.0.2 之后已集成的本地改动，不是新版本的发布声明。要求沿 [现行规格](../spec/local-first-library.md#画布连线与归档)，视觉层级沿 [DESIGN](../DESIGN.md)，当前交付依赖见 [PROGRESS](../PROGRESS.md)。

## 工程接缝

- [Atlas](../web/app/atlas.tsx)保留原有图文编辑、详情、原件、全量列表与归档，主画布改为节点和标题；[预览组件](../web/app/relationship-preview.tsx)只呈现 3∶4 卡片，不持有另一份正文或位置。
- [共用几何与排列](../shared/relationship-layout.mjs)提供节点 200×56、预览 300×400、直接邻居及确定性的关联分组；新建位置使用相同节点边界。已有坐标继续读回，主动整理才保存新位置。
- [位置参数](../shared/layout-request.mjs)限定有效 ID、坐标、版本、稳定请求键及 1000 条上限。[Library](../server/library.mjs)先检查全部版本，再在一个事务中修改位置和保存原坐标回执；[工具分发](../server/tools.mjs)供网页、CLI 与 stdio MCP 使用。
- 恢复回执的操作与限度见 [接口合同](interfaces.md#整批位置与恢复)。回执仅备份坐标与版本；完整资料继续沿原资料包导出／隔离恢复。
- 拖动和键盘位置写入在整批操作前完成，迟到回执保留较新版本；整批结果还需回读当前资料。图文编辑的草稿、原件和保存流程保持原职责。

## 审查修正

聚焦根节点离开可见集合时退出聚焦，恢复原视野，保留兜底返回与可达焦点；阅读归档详情不再让其他节点全部变暗。新建避让按节点而非预览尺寸维护；清理仅剩测试调用的旧卡片网格助手，临时排列测试改为实际关系排列。无变化保留最近一次实际变更的原位置备份，重放仅确认历史写入后读取当前位置；窄屏也保留下载入口。

## 节点标题显示调整

2026-10-07 根据最新反馈，将可见节点改为圆点与点上方的单行标题，去掉原胶囊容器的底色、外框和阴影。连线使用同一圆点锚点，点击后才展开卡片。200×56 仅作为无形点击／避让区域；数据坐标、标题原文、正文与关联保持，完整标题在提示及卡片可读。两版本地网页实测了透明无框的节点区域、圆点上方单行标题、点中心连线及三步打开，正文与坐标逐项保持；工程检查 38／63 项通过。独立只读审查确认此轮无阻塞问题；线上部署与私人旧布局仍未改变。
