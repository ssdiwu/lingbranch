## 安装与升级

源码需要Node.js22.22.3或更新版本，按 [README](../README.md)运行 `npm ci`、`npm run build`、`npm start`。已有库升级前停止网页、MCP和CLI写入并完整备份，保留数据目录；首次打开旧库按事务升级到资料库版本3。恢复只交付新目录，旧v1/v2包保持严格校验，不覆盖正在使用的库。

发布内容为GitHub源码ZIP／tar.gz与版本说明。基础网页不依赖模型API或维护者账号；AI接入按实际客户端支持的MCP／CLI核验，源码技能存在不等于宿主已经重新加载。
