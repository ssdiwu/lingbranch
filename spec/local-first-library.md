# 个人资料库的首条使用路径

## 定位与依据

用户需要在自己的环境保存灵感，并让网页和已有的 AI 客户端检索、修改、关联同一份内容。首版默认一人一库，优先本机运行与自有服务器部署。

本规格来自已确认的开源定位和现有灵感库的有效行为，定义独立部署版应达到的结果。下面的验收项是要求；实际运行结果与未覆盖范围单独记录在工程验证说明中。

词义以 [GLOSSARY.md](../GLOSSARY.md) 为准，共用体验见 [DESIGN.md](../DESIGN.md)。工程边界与验证入口的建设前提见 [架构与工程前提](../doc/architecture.md)。

## 首条完整路径

1. 用户在自己的环境启动资料库，首次打开得到空库和新增入口。
2. 用户保存两条带标题、内容、来源和标签的灵感，为其中一条添加附件。
3. 用户通过搜索、标签或全量列表找到它们，在画布上建立连线。
4. 支持相应连接方式的 AI 客户端读取其中一条，按用户指令更新内容或标签；网页读回相同结果。
5. 用户清除筛选并重新打开资料库，确认记录、附件、连线和持久布局仍在。

导出与恢复属于首版的数据可迁移范围，通过独立的隔离资料库场景验收，不覆盖正在使用的资料库进行验证。

## 行为与公开边界

### 资料库与访问

- 网页和 AI 工具读写同一份资料库，遵守一致的校验、冲突和保存规则。
- 本机模式可省去账号体系，在本地信任边界内运行。AI 客户端可通过支持的本地工具连接方式操作，不要求注册维护者的平台身份。
- 服务器模式使用部署者自己的数据存储与访问保护。未通过访问保护的请求不能读取、导出或修改资料库；客户端不能靠自行声明身份绕过边界。
- 基础功能无需大模型 API，不自动调用模型服务或产生模型调用费用。用户选择的 AI 客户端承担其自身的登录与模型调用。
- 其他平台只有在其后端、持久存储和接口连接能力经过验证后，才列为已支持的部署环境。

### 灵感保存与读取

- 一条灵感有稳定标识，可保存标题、内容、来源说明、来源链接、来源时间及多个标签。附件、连线与布局归属于同一份资料库。
- 标题帮助辨认内容主体与保存用途；用户明确给出的标题保留，更新正文不自动重命名。
- 保存和更新明确返回已创建、已更新、已存在或未变化等结果，并提供能读回同一记录的标识。
- 对可重试写入使用稳定请求标识。相同请求重试不重复创建记录；同一标识承载不同请求不能静默覆盖。
- 更新可发现版本冲突。发生冲突时保留既有内容，提示重新读取并明确返回失败，不把过期草稿覆盖成功当作结果。
- 无效输入和存储失败返回可识别的错误，不把部分完成伪装成整个操作成功。

### 标题引导

标题优先采用“可识别主体：具体用途或适用场景”，用途以提供或已核实的正文为依据，避免裸项目名、模糊“参考／详解”、宣传语和涨星数量，不把候选能力写成已经实现。用户明确指定的标题仍原样传递；缺少用途时可保留“待补用途”草稿并询问，不编造。网页输入提示使用 `web/lib/inspiration-title-guidance.json`；AI／CLI 调用者在保存前按本节完成命名。此规则是引导，不强制冒号格式、不自动改写已有标题、不增加模型调用或费用。未提交的标题字段仍保持原值。

### 检索与标签

- 搜索与标签筛选用于定位相关灵感。检索范围可明确区分活跃记录与归档记录。
- 全量列表无需关键词或标签，包含未打标签的记录，能够完整分页遍历；每页提供继续读取所需的信息和完成状态。
- 需要全部记录时沿分页入口遍历，不能靠多个宽关键词的并集声称全量完成。
- 标签管理支持查看已有标签、复用、重命名或合并、从记录中移除；只改变预期标签关系，不损坏正文、附件、连线或位置。

### 画布、连线与归档

- 首次读取及没有缓存资料的失败重试，以圆点和短标题占位显示加载状态；不展示预览卡片或误报空库。占位不可操作，有可访问的读取说明，减少动态效果时保持静态。成功后直接呈现点与完整标题，只有用户打开预览才出现卡片。刷新已读回的资料时保留当前画布，失败保留已读资料并提供错误反馈；过期读取响应不能结束较新请求的加载状态或覆盖其结果。
- 主画布以关系优先：每条灵感呈现为圆点，标题文字悬在点的上方，不显示卡片或胶囊的底色、外框与阴影。未选中点直径 24 像素、以较高透明度呈现；选中点直径 36 像素且更清晰，直接关联点保持较小尺寸并适度突出。尺寸变化固定圆心，标题、光圈与完整点击区域留出空间。原标题在节点上单行完整呈现，不因长度、缩放或点间距添加省略号；按完整文字边界安排空间，不改写保存的标题。视口外内容通过平移浏览，悬停与可访问名称继续保持完整。连线连接圆点中心，选中与键盘焦点以圆点光圈和文字强调表达。第一次点击圆点或标题显示卡片预览，再点击预览进入右侧完整详情。键盘焦点移到视口外节点时用同一画布视野定位，让焦点可见；浏览器不另行原生滚动绘图区。键盘 Enter／空格遵循相同顺序；拖动节点不误开预览或详情。全量列表、分享链接等明确的读取入口可直接打开详情。
- 预览卡片统一为宽高 3∶4，图片、标题和摘要优先，资料数量与日期后置。预览在视口中保持可读尺寸，窄屏按同比例缩小，长内容在详情中完整查看；预览浮在画布上，不成为需要避让的永久节点。
- 在 35% 及以上的正常阅读视野中，圆点以屏幕 24／36 像素呈现，标题保持可读字号与完整单行文字；连线仍接在同一圆心。更小的全图概览允许节点继续缩小，避免密集重叠，放大后恢复阅读；不改变持久坐标或标题原文。
- 选中节点时突出它的直接关联节点和连线，其他节点仍可辨认；提供只看直接关联及返回全部的入口。聚焦节点归档、恢复或离开当前筛选时退出聚焦，保留返回和可达焦点。依据已保存的无方向连线呈现，不从标签或正文自动生成关系，不套用词典引用的箭头语义。
- 已保存关联绘制为实线。选中节点时，当前可见、共享至少一个原名标签且尚未与该点保存关联的节点，使用淡虚线表示“同标签提示”，并可查看具体共同标签；无选中节点不绘制标签虚线，不能生成全组两两连接。共同标签区分大小写，重复标签或多标签只产生一条提示，已经保存的反向关联同样排除。依据面板选定标签时只提示该标签的共同成员；缺失、被筛掉或归档在另一视图的端点不进入提示。提示仅由当前已读资料派生，不分析正文、不保存关系、不改坐标，不计入已有连线数量、直接关联聚焦、导出或 MCP 查询。真实连线增删或标签刷新后同步更新提示。
- 每个节点对应一条灵感。新节点应放在没有已有节点占用的位置，标题命中区域不能相互遮挡；不为安置新节点自动重排旧布局。
- 持久保存的节点位置与画布视野，在重新打开后恢复。筛选或只看直接关联形成的临时显示与持久布局区别对待；清除筛选可回到原布局。
- 用户主动选择「整理位置」时，使用主题辅助自然布局整理全部活跃节点（一次最多 1000 条，超出时先拒绝计算和写入）。已有无方向连线提供主要牵引，共享标签提供较弱的主题靠近；多标签共同参与，未标标签或没有关系的节点自然散开。计算确定、有限且避让完整节点区域，不逐行平铺，不根据主题新增连线、改写标签或调用模型。聚合依据属于当前视图的派生展示，不是另一份资料或关联。画布明确说明整理依据为已有连线与共享标签，未分析正文语义；提供各标签的真实成员数量与高亮入口，选中节点可读其已有标签与直接关联。高亮不筛选、重排、写入标签或新增连线，直接关联聚焦中保留聚焦根与当前集合；清除高亮恢复原显示。当前位置也可能包含手工调整，不把当前标签统计说成上次布局的历史推导记录。去掉重叠的大面积主题底色，避免将非成员圈入伪分组。布局及新建避让按完整原标题长度计算，覆盖最小正常阅读视野下的标题、选中点、焦点与触摸区域。整理与筛选默认保留可读视野，用户可显式适配全部进入概览；概览按完整范围计算缩放，不沿用正常阅读下限。持久视野与资料包接受 0.0000001 至 2.5 的缩放，零、负数或无穷值拒绝；概览提供一键回到 35% 阅读。
- 手工移动沿原持久规则保存；打开、刷新、点选、筛选清除及标签更新不自动替换持久坐标。主动再次整理可以重新安排手工位置，先保留原位置再一次性提交；任何记录版本冲突、身份校验或存储失败都拒绝整批写入。操作提供稳定请求标识，同请求重试返回原回执，不覆盖后续修改；同标识不同参数拒绝。无变化不推进上次可恢复位置；历史请求的重放只确认原操作，必须读回当前布局后反馈。
- 整理回执包含原位置和保存后的版本，可在当前页面恢复上次位置，也可下载回执保管。恢复仍校验保存后的版本，不能覆盖后来网页或 AI 的编辑。整理与恢复仅修改位置及必要的记录版本，不改变标题、正文、原件、标签、归档或连线。
- 平移、缩放、适配全部及选中关联聚焦均可中断；按下和拖动即时响应，减少动态效果设置下保留静态反馈。只看直接关联、检索和归档视图中的移动仅调整当前显示，不能暗中保存全库排列。
- 连线连接两条不同的活跃灵感，无方向。同一对灵感的重复或反向建立请求返回已有连接，不生成重复线。
- 可以查询灵感的关联项并移除连线；移除只改变连接，不删除任何灵感、附件或卡片位置。
- 实线保存关系类型、理由及独立版本。类型为 related（关联）、workflow（工作流衔接）、example（案例归属）、application（方法应用）、extension（概念延伸）；理由为不超过 500 字的普通文字。无方向画法保持，类型不代表流程已经实施、因果已证实或任务依赖。旧连接保留标识与两端，默认关联、理由空白并明确待补；初始版本仅用于并发控制，不当作历史修改日期。
- 点击实线或详情关联项可查看与编辑说明。新网页连接先填写非空理由再保存，旧工具只给两端的调用继续支持；新工具调用按已读内容提供理由。重复或反向建立只产生同一条连接；显式类型或理由与已有连接不一致时拒绝，不借重复建立改写说明。
- 新调用可提供稳定 idempotencyKey；同请求重试只确认原写入，连接后来编辑或移除时不能被重试覆盖或重建。修改用 update_inspiration_connection，提供 connectionId、expectedUpdatedAt、稳定请求键及 patch；冲突保留草稿，重新读取后由用户明确采用最新或保存其合并结果。无变化不推进版本。删除可提供连接版本，旧版本拒绝，原无版本的移除调用保持兼容。
- 网页、HTTP、CLI、MCP共用同一连接规则，说明更新只改连接和回执，不改两端、正文、标签、原件、归档或位置。SQLite 升级到资料库版本 3，连接新增列在一项事务中完成；资料包版本 3 保留说明和版本，恢复旧 v1/v2 包严格按旧形校验后补默认值，仍仅交付新目录。插件使用新增 D1 迁移并保留原身份及 R2，完整导出包含关系说明。
- 用户授权全库整理时，AI逐条阅读用途和正文，保留有依据的旧连接，新增关系写清具体理由与候选边界；共同标签和通用评估文字不能单独成为实线依据。整理前完整备份，写入前核对两端最新资料与已有关系，失败保留可复验回执；前后正文、原件、标签、归档、节点位置与视野保持，未另行授权不重排坐标。
- 归档可恢复，与删除区分；全量列表显式决定是否包含归档项。

### 附件、导出与恢复

- 附件原件与检索文字分开保存。网页和 AI 均能定位已保存的附件；可读取范围遵守所在资料库的访问保护。
- 上传校验文件元数据、实际内容及完整性；重复请求不产生重复附件。中断或失败说明哪些内容已经保存、哪些需要重试。
- HTML 等主动内容不因保存、索引或下载而作为服务器代码执行。不把未验证的 OCR 或全文理解写成已支持能力。
- 导出覆盖灵感、来源、标签、附件原件、连线和持久布局；导出本身不修改原资料库。
- 恢复使用受控目标与完整性检查，成功后可读回上述内容与关系。验证恢复时使用独立的空资料库；错误包或无法安全写入时不覆盖已有资料。

## 图文正文升级合同

### 正文、图片与文件的组织

- 网页提供可视化 Markdown 图文编辑，基础能力包含普通段落、标题、列表、引用、代码、链接与插入图片。图片和截图能放在文字中间，并在前后写说明；新功能不调用大模型 API。
- 编辑器与共享层统一使用 CommonMark；不启用 GFM 裸 URL 自动链接、删除线、任务列表或表格。原有文字、反斜杠与换行不能因编辑器载入、保存和再载入而被追加转义字符。
- 纯文本的末尾换行、空白正文及字面字符引用按字符保留。必要的换行、制表或边界空格可在同一 Markdown 正文中用标准数字字符引用表达；读取与编辑使用同一文本序列化规则，不另存原文，不删除或追加反斜杠补救。
- 新建默认进入图文编辑。旧纯文本切换为图文时先按字面转义，原有 `*`、`#`、图片语法和链接不能变成排版或外部图片；切回纯文本保留可读文字及图片说明，所有已保存原件继续可访问。切换前尚未保存的正文图片转为待保存原件，不因格式切换丢失。
- 正文有明确格式标记。旧记录默认仍为纯文本，升级不能把旧文本中的符号重新解释为 Markdown，也不改写已有正文、原件、记录标识、位置或关联。旧记录在用户实际转换或编辑保存时才进入图文格式。
- Markdown 正文是正式内容的唯一文本来源；编辑器内部状态、浏览器草稿、渲染结果及检索摘要由它派生，不持久保存第二份可独立修改的正文。
- 图片原件继续使用当前资料库的附件保存、校验和访问入口。正文引用稳定的原件标识，不能将临时预览地址、图片字节编码、机器目录、访问令牌或特定部署域名当作持久图片来源。
- 引用必须实际存在、属于当前灵感且允许安全图片预览。保存前校验真实 Markdown 图片节点，不把代码示例或普通文字里的类似表达误当引用。不存在、跨记录、临时或不允许的图片引用明确拒绝。
- 读取图文按正文顺序展示图片及相邻说明。文件附件区主要列非图片文件；暂不能预览的图片、旧图片及未插入正文的原件仍有明确访问路径，不能因过滤或缺少引用而消失。
- 移除正文中的展示引用不自动删除原件。查看大图、下载原件、完整导出与恢复仍覆盖所有已保存资料；不增加自动清理原件的操作。
- 卡片预览采用 B 方向及统一 3∶4 比例，正文可读摘要、图片预览与标题优先，图片/文件数和日期后置。归档状态独立可辨认，不恢复“文字灵感”分类。画布节点边界满足防重叠；旧布局只在用户明确整理时重排。
- Markdown 不执行 HTML、脚本或主动内容，不自动加载或下载外部图片，不接受客户端自报身份。普通来源链接与本库原件引用保持区别。
- 行内及引用式 Markdown 图片遵守同一原件规则；普通链接仅为有效的 HTTP、HTTPS 或 mailto 链接提供点击入口。阅读保留基础排版，摘要连接同一段落中的文字而不在粗体、斜体或行内代码边界插入空格。

### 保存、其他入口与兼容

- 复用网页、HTTP、MCP 与 CLI 的共用资料库操作及校验，不另建编辑器资料库或私人平台入口。读取返回正文及格式，AI 能修改同一篇正文并通过既有工具获取原件。
- 新格式字段保持向后兼容；旧请求按原有口径处理，新增默认值不能改变旧幂等请求的摘要。历史凭据仍能按原参数重试，不能因库升级产生冲突或重复。
- 图片先完成原件保存和索引，再提交含稳定引用的正文。新记录需要取得标识时允许分阶段写入，但必须如实反馈已完成部分，只有最终正文写入及读回成立后才报告图文保存完成。
- 每阶段使用稳定请求标识，重试不生成重复记录或原件。上传成功、正文失败或发生版本冲突时，保留草稿和已经获得的标识；不得自动换版本覆盖其他端的修改。
- 保存期间冻结本次提交内容或明确区分其后新增的编辑；成功回执不得关闭或丢弃尚未保存的新输入。异步上传回调不得插入其他记录或覆盖用户后续编辑。
- 旧库和旧资料包能在保护内容的前提下升级或恢复。新资料包包含正文格式、图片引用及全部原件，验证先于交付；仍只恢复到新目录，不覆盖正在使用的库。
- 新导出使用资料包版本 3，保留正文格式及连接说明；旧版本 1／2 按原结构严格校验后补默认连接说明，版本 1 另补纯文本格式。纯文本中的图片语法按字面处理，只有图文格式校验图片引用；各版本均先完成关系、原件及重试凭据校验再交付。
- 网页与 AI 对 Markdown 的可读文本使用一致的摘要和检索规则，正文说明、图片说明、标签、文件名及既有索引文字可检索；不把渲染标记或内部引用当作用户内容。

### 本轮验收

- 使用临时资料库保存两张自编图片交错正文及一份 PDF 文件；卡片显示两张图片和一个文件，正文图文顺序正确，PDF 在文件附件区，原件可下载且校验一致。
- 从独立 MCP 或 CLI 读取并更新一段说明，网页读回同一正文、格式和图片引用；标题、原件、标签、连线及布局保持预期状态。
- 上传中断、重复提交、正文写入失败、过期版本及失效引用分别有可判定结果，草稿与已保存原件保留。
- 旧纯文本记录与旧资料包升级后原文、原件和布局不变；原有幂等请求继续有效。新图文在服务重启和隔离恢复后仍完整可读。
- 可视化编辑器验证中文输入、插图、图片前后编辑、撤销/重做及 Markdown 再载入，不能以静态图文预览替代真实编辑能力。
- 生产构建、现有工程检查、新增行为验证、真实浏览器核对和独立只读审查分别成立。真实服务器与所有 AI 客户端的适配不由本轮结果推导。

## 本轮标题与聚合依据验收

- 自编中文、英文、宽字形、多标签与最长 200 字标题在正常阅读视野均完整单行显示，文字节点与保存的原标题相同，无 CSS 截断；以实际渲染宽度、可读字号及代表性视觉识别验收，不靠 tooltip 或元素存在放行。
- 整理后的完整标题、选中点及焦点无相交；新建同样按完整标题避让，未主动整理的旧坐标不暗中改写。
- 聚合依据展示真实共享标签及已有连线数量；点击标签恰好高亮其全部当前成员，多标签可被不同选择识别，无标签不误入成员。操作前后资料、坐标与关系保持。
- 延迟读取期间只有圆点与短标题占位，失败、重试、空库和成功分别反馈；有资料时刷新不退回占位。选中点的同标签虚线只覆盖可见真实成员，已保存实线不被重复提示，标签筛选、直接关联聚焦及刷新后状态正确。点选与清除前后实际持久关系和坐标保持。
- 完整标题、点选卡片、详情、拖动、刷新、恢复与原件路径在两侧分别验收；超长标题通过平移读取，显式全图概览与默认可读视野区别核对。

## 验收场景

### 独立版首个实现合同

- 默认本机网页仅监听 `127.0.0.1`，校验 Host、Origin 与浏览器跨站请求；网页写入发送专用请求头。服务器模式必须同时配置至少 32 字符的访问令牌与明确的站点地址，缺失时拒绝启动。服务器通过 Bearer 令牌或登录后签发的 HttpOnly、SameSite=Strict 会话校验访问；公网使用 HTTPS 反向代理，不信任转发的身份头。
- 本机 MCP 使用标准输入输出（stdio），由 AI 客户端启动独立进程，使用与网页相同的数据目录和操作模块。它不需要网页登录，但需要本机文件权限。首个版本不提供远程 HTTP MCP 或 OAuth；服务器提供有相同访问保护的 HTTP 资料库接口。
- 本机 CLI 与 MCP 共用工具分发、输入校验和保存规则；通过显式绝对数据目录操作同一资料库。提供工具 schema 发现、列表/搜索/读取及通用 JSON 工具调用。stdout 输出单个 JSON 结果，失败为 `ok:false` 且退出码非零；配置查看不创建或打开数据库。完整分页只在无遗漏、无重复且数量一致时报告完成。
- 仓库提供可安装的 LingBranch 技能正文、参考与助手脚本，复制为普通文件，安装拒绝覆盖已有目标。搬移技能后通过显式项目路径与数据路径运行，不依赖维护者的机器或私有账号；它依赖已安装的应用，不自动修改客户端 MCP 配置、模型账号或持久授权。
- 新建、编辑、标签批量变更和附件上传使用 `idempotencyKey`。同一请求标识与同一请求重试返回原操作凭据；同标识不同参数返回 `conflict`。编辑、拖动及归档传入读回的 `expectedUpdatedAt`；附件为独立不可变对象，不改变正文版本。连线以规范化的无序记录对查重，移除连线可重复执行。
- 标签只去除首尾空白、去重，保留用户的大小写和词义；不继承原型中针对维护者项目的标签别名。
- 全量列表默认包含归档，提供 `limit`（1–50）、`cursor`、`nextCursor` 和 `hasMore`。按创建顺序稳定遍历；遍历期间新增记录不进入当前快照，之后从第一页重新读取。网页提供全量列表入口。
- 单个附件上限 20 MiB，上传须提供 SHA-256（内容校验摘要）并检查实际字节数；图片按文件签名验证，其他文件只作下载。仅对 UTF-8 文本附件提取检索文字，支持人工填写索引文字，不承诺 OCR 或 PDF 全文识别；不从外部地址自动下载附件。
- MCP 上传接收边界涵盖 20 MiB 原件的 Base64 编码开销；读取原件按最多 512 KiB 分段返回，提供 `offset/nextOffset/complete`，沿偏移读到完成后按总字节数与 SHA-256 校验。客户端自身的文件输入限制仍需独立确认。
- 导出格式为版本化的 `.lingbranch.json.gz` 完整资料包，包含元数据、原件字节、每个原件的校验摘要、重试凭据及布局。首个实现限制解压后资料包为 128 MiB，超过限制明确失败。恢复为本机命令，先验证所有结构、关系与原件，再在临时同级目录构建资料库，最后原子交付到尚不存在的目标目录；拒绝覆盖已有目录。
- 正文、位置更新和标签变更在 SQLite 事务内完成。附件先完成原件写入，再提交元数据和重试凭据；失败允许留下不被引用的原件，但不得产生引用半个文件的成功记录。重试校验已存在原件后继续。

这些约束用于当前实现与验证，不扩大平台或客户端兼容承诺。

验证接缝为实际网页、对外 AI 工具和部署后重启流程。工程实现后记录具体运行命令、客户端、配置与结果，不能用内部函数通过替代整条用户路径。

| 场景与准备条件 | 用户操作或工具调用 | 可判定的结果与边界 |
| --- | --- | --- |
| 新部署、空资料库 | 打开网页，保存两条灵感 | 空库不包含维护者数据；两条记录有不同稳定标识、可读回，新卡片不重叠 |
| 已有用户布局 | 网页或 AI 新增灵感 | 新卡片避开旧卡片，旧位置、连线和视野保持预期状态 |
| 已保存一条记录 | 相同写入请求重复提交；更换内容复用相同请求标识 | 前者读回同一条记录，后者明确拒绝冲突；不重复创建或静默覆盖 |
| 网页与 AI 均已读到同一版本 | 一方保存后，另一方提交过期修改 | 明确版本冲突，先保存的内容仍在；重新读取能得到当前内容 |
| 有未打标签和归档记录，数量跨越分页 | 无搜索词获取全量列表并逐页读取 | 每条符合范围的记录出现一次，结束可辨认；未打标签记录不遗漏 |
| 已有标签与两条相连记录 | 修改标签、筛选、清除筛选，再读取记录 | 标签结果正确；临时展示不覆盖持久布局，正文、附件和连线保留 |
| 两条活跃灵感 | 建立连接，重复及反向建立，重启后查询，再移除 | 仅一条持久连线；移除后两条灵感、附件与布局仍在 |
| 已建立 AI 连接 | AI 检索、读取与修改，网页刷新读回 | 操作同一记录，返回值与持久结果一致，不产生第二份资料库 |
| 同一绝对数据目录，CLI 与独立 MCP 进程 | CLI 保存/更新后由 MCP 读回，重复提交与过期修改 | 读到同一记录；重复不新建，过期版本明确冲突；CLI 错误可由 JSON 和退出码识别 |
| 新技能目标与已有技能目标 | 安装并从独立目录运行助手，再尝试重复安装 | 文件均为普通文件，显式配置可定位同一资料库；已有技能不被覆盖，配置查看不创建库 |
| 有附件与连线的资料库 | 重启应用，下载附件原件 | 元数据、正文、连线与布局仍在，附件内容完整；仅程序重启不丢数据 |
| 相同资料库 | 模拟保存或上传中断，沿原请求重试 | 结果可辨认、可恢复，不出现重复记录或不完整原件被报告为成功 |
| 配置为服务器模式 | 未授权请求读取、写入、附件访问与导出 | 请求被拒绝，数据与布局不变；客户端自报身份不能获得访问 |
| 有完整数据的原库与独立空库 | 导出并恢复到隔离空库，逐项读回 | 原库不变；内容、关系、布局和附件完整；错误包不能覆盖已有数据 |

## 首版非目标

- 多人共享、团队协作、权限角色系统或维护者提供的统一云服务。
- 自动调用大模型生成内容、后台采集榜单或对外社交发布。
- 所有 AI 客户端和所有站点平台的一键兼容承诺。
- 在初始化中迁移维护者的真实资料、复用其私有站点凭据，或改变原网站的共享范围。
